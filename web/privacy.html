HV Dashboard ▶ YouTube Analytics

Privacy Policy

Effective date: November 8, 2026

HV Dashboard is a personal, non-commercial analytics dashboard for the HVenom YouTube channel. It is operated by the channel owner to view aggregate performance data for that single channel. This policy explains what data the dashboard accesses, how it is used, and how it is stored.

Data the dashboard accesses

The dashboard uses the channel owner's own Google account to read that channel's YouTube analytics and video metadata. It does not access data belonging to any other YouTube user, viewer, or channel.

  • Aggregate views, estimated watch time, and subscriber gained/lost counts for the channel.
  • Public video metadata such as video ID, title, and content type (video or Shorts).
  • The channel's current subscriber count.

How access is authorized

Access is granted through Google OAuth 2.0 using these read-only scopes:

  • https://www.googleapis.com/auth/yt-analytics.readonly
  • https://www.googleapis.com/auth/youtube.readonly

The channel owner can revoke this access at any time from the Google Account permissions page.

Storage and retention

OAuth credentials are stored locally by the channel owner and as encrypted GitHub Actions secrets. Raw API responses are used only inside the build environment. The dashboard publishes aggregate channel analytics as a static data file; raw API responses and credentials are not published. Aggregated analytics are retained for as long as the dashboard is online.

Public nature of the site

This site is publicly reachable and displays aggregate statistics for the HVenom channel. It does not display information about individual viewers, and it does not require or support visitor accounts.

Cookies, analytics, and tracking

This site does not set cookies, run third-party analytics, or track visitors. The only third-party request is the Chart.js library loaded from a public CDN.

Sharing

Data is not sold, rented, or shared with advertisers. The site is hosted on GitHub Pages, so standard web-server logs may be processed by GitHub as described in GitHub's privacy statement. Data may also be disclosed if required by law.

Google API Services User Data Policy

The dashboard's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Google user data is used only to provide and improve the dashboard's analytics features, and is not used for advertising or sold to third parties.

Children

This site is not directed to children and does not knowingly collect information from children.

Changes

This policy may be updated as the dashboard changes. The effective date at the top of this page will be revised when that happens.

Contact

For privacy questions, contact the channel owner using the contact email listed on the HVenom YouTube channel's About page.
